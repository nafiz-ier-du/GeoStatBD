GitHub Pages Deployment Guide

  1. Create a new repository on GitHub.com (e.g., geostat-bd).
  2. Save this complete file code locally as index.html.
  3. Upload/Commit index.html directly to your main repository branch.
  4. Go to your repository **Settings** > **Pages**. Under "Build and deployment", select **Deploy from a branch** (main / root).
  5. Your live web app URL will be generated instantly for free!
