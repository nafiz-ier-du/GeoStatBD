How to Publish GeoStat BD Live on GitHub Pages

1

Save Code Locally

Save this entire single-file code as index.html on your computer.

2

Create a GitHub Repository

Go to GitHub New Repository, name it geostat-bd, and set visibility to Public.

3

Upload index.html

Click on "uploading an existing file", drag and drop your index.html file, and click Commit changes.

4

Enable GitHub Pages

Navigate to your repository's Settings tab → Click Pages in the left sidebar. Under Build and deployment, select branch main and folder / (root), then click Save.

Live URL Generated

Your live web application will be accessible at: https://yourusername.github.io/geostat-bd/
